1. Point your Slack app's Event Subscriptions Request URL at:
{{- if .Values.traefik.ingressRoute.enabled }}
     https://{{ .Values.traefik.ingressRoute.host }}{{ .Values.traefik.ingressRoute.path }}
{{- else if .Values.ingress.enabled }}
     https://{{ .Values.ingress.host }}{{ .Values.ingress.path }}
{{- else }}
     (no ingress enabled — expose the gateway Service yourself)
{{- end }}

   Slack will immediately POST a url_verification challenge; the gateway
   answers it automatically.

2. Subscribe the bot to at least `app_mention`, then invite it to a channel
   and mention it.

3. Watch it work:

   kubectl -n {{ .Release.Namespace }} logs -l app.kubernetes.io/component=gateway -f
   kubectl -n {{ .Release.Namespace }} logs -l app.kubernetes.io/component=agent -f

   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "mushroom.fullname" . }}-gateway {{ .Values.gateway.service.port }}
   curl localhost:{{ .Values.gateway.service.port }}/stats
